Made for readers

Everything your library needs

Most reading apps are locked to a cloud service or stop at a simple list. Leafmark gives you a complete library — with progress, history and statistics — that runs on your own server and belongs to you.

Search across six sources

Search by title, author or ISBN and Leafmark queries Google Books, Open Library, BookBrainz, the German National Library, Big Book API and Amazon at once. Results are merged and deduplicated by ISBN.

Reading progress

Log the page you are on, see how far you have come as a percentage and explore a history chart of every session. Leafmark also tracks when you started and finished each book.

Yearly reading challenges

Set a goal for the year and watch the progress bar grow as you finish books. The stats page shows how the year compares to previous ones, with a month-by-month breakdown.

Tags, series and covers

Organise books with colour-coded tags and group them into series with position ordering. Each book can have multiple cover images — upload your own, reorder them and pick the primary.

Family accounts

Every user has their own independent collection. Group family members with join codes so they can find each other; statistics and challenges are always personal and never shared.

Your data, your server

Leafmark runs on your own server. No telemetry, no cloud account, no subscription. Sign in with a passkey, a single-use email link or a password with mandatory two-factor authentication.

How it works

From empty shelf to full library in minutes

Search for a book, add it, start reading. Leafmark keeps up with you.

  1. Search or import

    Search by title, author or ISBN across six sources, paste an Amazon URL, or import your entire Goodreads library in one go.

  2. Set your status

    Mark a book as Want to Read, Currently Reading or Read. Leafmark records when you started and finished.

  3. Log your progress

    Update your current page whenever you read. The history chart shows how your reading pace changed over time.

  4. Explore your stats

    See which year you read the most, your top authors, your average rating and how close you are to this year's challenge.

Import from anywhere

Bring your library with you

Leafmark searches multiple sources in one query and imports from wherever your books already are.

Goodreads CSV

Export your Goodreads library as a CSV file and import it. Shelves become reading status or tags, series are extracted from the title, and a preview step shows duplicates before the import runs.

Library backup (ZIP)

Export your entire library — books, covers, tags, progress and challenges — as a ZIP archive. Import it on another instance with duplicate handling: skip, overwrite or keep both.

Six book sources

Google Books, Open Library, BookBrainz and the Deutsche Nationalbibliothek need no API key. Big Book API and Google Books gain richer data with an optional key set in the admin settings.

Installation

Up and running in an afternoon

Leafmark ships as a ready-made Docker image from the GitHub Container Registry. You need a small server, a domain with HTTPS and optionally an SMTP account for passwordless sign-in. No programming required.

  1. Server & database

    A small virtual machine or home server with Docker, for example managed with Coolify, and a PostgreSQL database. The database is set up automatically on first start.

  2. Deploy the image

    Start the Leafmark image with its environment variables using deploy/docker-compose.coolify.yml. Set the domain, the app key and the database credentials.

  3. Register & start reading

    Open your domain. The first registered account becomes the admin. Search for a book, add it and start tracking.

FAQ

Frequently asked questions

What is Leafmark?

Leafmark is a free, open-source web app to track your personal book collection. You add books by searching across six external sources or by scanning an ISBN, log your reading progress, set yearly challenges and explore your reading statistics. It runs on your own server.

What do I need to run Leafmark?

A small server that runs Docker, a PostgreSQL database, a domain with HTTPS and optionally an SMTP account for passwordless sign-in links. The reference setup is Coolify; any Docker Compose host works.

Can the whole family use it?

Yes. Every user has their own independent book collection. Family members can be grouped with join codes; statistics and challenges are always personal and never shared. Admins can see usage statistics but never other users' books.

Can I import my Goodreads library?

Yes. Export your Goodreads library as a CSV file and import it into Leafmark. Shelves become reading status or tags, the series and main author are extracted automatically, and a preview step lets you check for duplicates before the import runs.

Where does book data come from?

Leafmark searches across up to six sources in one query: Google Books, Open Library, BookBrainz, Deutsche Nationalbibliothek, Big Book API and Amazon (by URL). Open Library, BookBrainz and the DNB are free and need no API key.

Which languages does Leafmark support?

English, German, French, Italian, Spanish and Polish. Every user picks their own language in the settings; the server default is set with APP_LOCALE.

Is Leafmark free?

Yes. Leafmark is free software under the GNU Affero General Public License v3.0. There are no licence fees, no subscriptions and no telemetry. You only pay for the server you run it on.
